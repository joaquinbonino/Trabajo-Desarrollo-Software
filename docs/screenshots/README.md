# Capturas de pantalla

Esta carpeta contiene las capturas incrustadas en el [README principal](../../README.md#capturas-de-pantalla).

Para regenerarlas, levantá el proyecto (`docker compose up --build`) y guardá cada captura con el nombre indicado:

| Archivo                  | Vista a capturar                                           |
|--------------------------|-----------------------------------------------------------|
| `catalogo.png`           | Catálogo de eventos (Home) con la barra de búsqueda/filtro |
| `detalle.png`            | Detalle de un evento con el botón de compra                |
| `mis-entradas.png`       | "Mis Entradas" con acciones de cancelar/transferir         |
| `compra.png`             | Mensaje de compra exitosa ("Congrats")                     |
| `admin-panel.png`        | Panel de gestión de eventos (admin)                        |
| `admin-formulario.png`   | Formulario de creación/edición de evento                   |
| `admin-reporte.png`      | Reporte de ocupación y ventas de un evento                 |

> Mantené los nombres de archivo: el README los referencia por ruta.
